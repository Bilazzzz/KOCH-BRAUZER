# KOCH BRAUZER 🌸

Минималистичная неоновая страница новой вкладки для Chromium
(Chrome, Brave, Edge, Vivaldi, Opera, Ungoogled Chromium). Manifest V3.

## Возможности
- Часы + погода двух городов (Open-Meteo, без API-ключа)
- Поиск: Google / DuckDuckGo / Bing / Яндекс / Brave + история с подсказками
- Категории и ярлыки: добавление, изменение, удаление, Drag&Drop
- 6 тем (розовая, фиолетовая, океан, изумруд, тёмная, светлая)
- Свой фон: **зацикленное видео**, изображение или неоновые орбы
- Свой аватар и подзаголовок
- Экспорт / импорт / сброс данных (всё локально, chrome.storage)

## Установка
1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку проекта.
3. Открыть новую вкладку.

## Горячие клавиши
- `Ctrl+K` — фокус на поиск
- `Ctrl+,` — настройки
- `Esc` — закрыть окна
- ПКМ по заголовку категории — переименовать/удалить

## Управление
- Тянуть за заголовок категории — смена порядка категорий
- Тянуть ярлык на другую карточку — перенос ярлыка
- Hover на ярлык → ✎ изменить / ✕ удалить
